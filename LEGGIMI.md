# Come pubblicare l'app su GitHub Pages

1. Vai su github.com, accedi e premi **New repository**. Chiamalo per esempio `giochi`, mettilo **Public** e premi **Create repository**.
2. Nella pagina del repository premi **uploading an existing file**.
3. Trascina dentro **tutto il contenuto** di questa cartella (index.html, manifest.webmanifest, sw.js e le cartelle `giochi` e `icone`). Non la cartella stessa: il suo contenuto.
4. Premi **Commit changes**.
5. Vai su **Settings → Pages**. In "Branch" scegli `main` e la cartella `/ (root)`, poi **Save**.
6. Dopo 1–2 minuti l'app è online a: `https://rdiianni-alt.github.io/giochi/`

## Installarla sul telefono
- **iPhone/iPad (Safari):** apri il link → tasto Condividi → **Aggiungi alla schermata Home**.
- **Android (Chrome):** apri il link → menu ⋮ → **Installa app** (o "Aggiungi a schermata Home").

## Aggiornare un gioco
Carica di nuovo il file modificato nella cartella `giochi` del repository (stesso nome). Chi ha l'app installata vedrà la nuova versione alla prossima apertura con internet.
